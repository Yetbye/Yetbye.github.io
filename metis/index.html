THE THESIS · 项目命题

真正自然的交互，
不是更快地回答。

“它应当知道何时接住你，何时把工作交给后台，何时回来简短说清结果。”

我们把智能拆成一条完整的生活链路：感知当下、理解意图、带着上下文行动、在必要时自然询问，再把证据和结果交付回来。对话只是入口，持续关系才是产品。

Μ

为什么叫 METIS
在希腊神话中，Metis 象征深思、谋略与明智判断。她代表的不是知识总量，而是在变化中选择恰当行动的智慧。

THE SYSTEM · 能力结构

从同一段生活里，
长出四种能力。

每个模块都必须可中断、可验证、可纠正。能力越接近你的电脑与生活，边界越要清晰。

A / PRESENCE

实时陪伴

语音、摄像头、屏幕与视频共享进入同一条时间线。附和不会误打断，明确改向可以停下；隐藏标签页仍能持续采样。

  • 双工语音
  • 可录字幕
  • 视觉回忆
B / DELEGATION

后台协作

用户继续交谈时，独立 Agent 执行多步工作。遇到真实信息缺口，问题回到前台被看见、被听见，并在回答后恢复同一任务。

前台?后台
  • 同任务恢复
  • 代际围栏
  • 有声交付
C / ACTION

本机行动

在授权范围内读取普通文件、播放桌面音频、操作原生控件，并通过 Edge 的 DOM / ARIA 与视觉后备完成网页动作。

> edge_read · accessible tree > local_play · playback receipt ✓ postcondition verified
  • 现有登录态
  • 动作后回读
  • 拒绝伪成功
D / CONTINUITY

个人记忆

事实、偏好、视觉情节、任务产物与承诺不再混成一团。每条长期记忆需要来源、时间与状态，允许纠正、抑制和遗忘。

YOU 偏好任务 事实承诺
  • 来源锚点
  • 跨会话
  • 可纠正遗忘

THE LOOP · 一次完整协作

听见不是终点，
完成也不是。

我们单独记录“任务完成”和“用户收到”。从一句自然委托到最终播报，每一步都有状态、证据与失败边界。

  1. 01
    感知语音 / 画面 / 上下文
  2. 02
    理解意图 / 风险 / 缺口
  3. 03
    委派独立任务与能力选择
  4. 04
    必要时询问前台有声提问，回答后继续
  5. 05
    执行动作、产物与状态回读
  6. 06
    交付摘要排队、播出与反馈
